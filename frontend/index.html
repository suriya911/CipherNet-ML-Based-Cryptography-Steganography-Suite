ML Cryptography + Steganography, Presented Clearly

Encrypt with AES-GCM, embed through U-Net, measure with detector and quantization benchmarks.

Pipeline

  1. Encrypt secret (`core/encryption.py`)
  2. Embed into cover (`core/steganography/model.py`)
  3. Train detector (`core/detector/cnn_detector.py`)
  4. Adversarial fine-tune (`core/steganography/trainer.py`)
  5. Serve via FastAPI (`api/main.py`)

Data & Storage

  • Processed covers: data/cover/
  • Secret pool: data/secret/
  • Model artifacts: models/
  • Large-file policy: releases / object storage / LFS
